# 用户工作目录

`workspace/` 位于安装后的 `chatbi-analyst/` 目录内，供用户保存自己的 Python、
SQL、Shell 等脚本，以及任务需要的本地输入和输出。它是客户端本地目录，
与 ChatBI 服务端的 workspace 资源不是同一个概念，不会自动同步到服务器。

Skill 自带连接程序位于 `scripts/`；用户编写或委托生成的分析脚本放在
`workspace/`。目录不存在时按需创建；安装位置不可写时，使用用户指定的
可写工作目录，并说明实际保存路径。多个用户应使用各自的本地工作目录。

查数通过 MCP 客户端完成，再用本地脚本处理授权结果。保存结果时记录
`result_id` / `run_id`、查询条件和时间，避免把历史文件当成当前查询结果。
权限撤销不会自动删除已经保存的本地文件。

目录存在不代表其中的脚本应自动执行；先检查本次要用的脚本及其作用，再按
用户任务运行。执行时明确工作目录和输入输出路径，不覆盖同名用户文件，
除非当前任务明确要求更新该文件。脚本仍受所在宿主的文件和执行权限限制。

更新或重新安装 Skill 时保留、迁移已有 workspace，不用空目录覆盖用户文件。
发布包只生成空的 workspace，不收录用户脚本、输入、结果或凭据；需要共享
某个用户脚本时另行明确选择。
